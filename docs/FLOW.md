# Reviewer Flow

This prototype models a Carousell refund dispute after buyer-seller disagreement.

1. Buyer purchases an item from a seller.
2. Buyer claims the item arrived cracked, chipped, damaged, or not as described.
3. Seller rejects the refund request.
4. Buyer escalates the dispute to Carousell.
5. Carousell reviewer opens the case in the reviewer tool.
6. Reviewer clicks **Run analysis**.
7. The tool returns a risk level, recommended action, signal breakdown, evidence used, and limitations.

The tool is decision support. It does not auto-reject claims and does not state that fraud is confirmed.
